# Visualizing Housing Market Trends: Analysis of Sale Prices and Features Using Tableau

## Project Description
This project analyses housing market trends using Tableau dashboards and stories. It helps users understand the factors that influence house prices, such as bedrooms, bathrooms, floors, house age, renovation year, and total sales.

The project includes an interactive website developed using the Dewi BootstrapMade template, along with Tableau visualizations to present meaningful insights.

## Technologies Used
- HTML5
- CSS3
- Bootstrap (Dewi Template)
- Tableau Desktop
- Tableau Public

## Project Files
- index.html – Home page
- assets/ – CSS, JavaScript, images
- data/Housing_Data.csv – Dataset
- tableau/HousingDashboard.twbx – Packaged Tableau workbook
- tableau/Story.twbx – Packaged Tableau Story
- tableau/sheet1.twbx - Packaged Tableau Sheet1
- tableau/sheet2.twbx - Packaged Tableau Sheet2
- tableau/sheet3.twbx - Packaged Tableau Sheet3
- tableau/sheet4.twbx - Packaged Tableau Sheet4

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Open `HousingDashboard.twb` or `HousingDashboard.twbx` using Tableau Desktop.
4. Explore the dashboard and story.
